# Contributing to phone-watchdog-mcp

Thanks for your interest in contributing!

## How to Contribute

1. Fork the repo
2. Create a branch (`git checkout -b feature/your-feature`)
3. Make your changes
4. Test locally
5. Commit and push
6. Open a Pull Request

## What We Need Help With

- New notification provider integrations
- Better screenshot handling
- Documentation and translations
- Bug fixes

## Reporting Bugs

Open an issue with:
- What you expected
- What happened
- Steps to reproduce
- Your environment

## Questions?

Open an issue or reach out.
